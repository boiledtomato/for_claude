# Herbarium — 鉛筆の植物図版のホーム画面

色を抜いた 19 世紀の植物図版を、そのままホーム画面にする Android ランチャー。

- 葉も花も**一枚ずつ別々に風に揺れる**。突風が左から右へ抜けていく
- **花や葉をタップすると蔦が伸び**、その先で花が開いて、中にアプリが現れる
- 1 か所に**複数のアプリ**を割り当てられる。蔦が枝分かれして同じ数だけ花をつける
- **蕾をタップすると花弁がほどけて開き**、アプリ一覧が咲き広がる

色は使わない。黒鉛一色で、面と陰影はハッチング（線の密度）で作る。

## 構成

```
android-launcher/
├── app/src/main/
│   ├── assets/flora/            # 版面の素材（tools/flora が生成。手で編集しない）
│   │   ├── manifest.json        #   茎の形、器官の付け根と揺れ、タップ判定
│   │   ├── organs/*.webp        #   葉と花を 1 つずつ焼いたもの
│   │   └── bloom/*.webp         #   蕾が開く連続コマ
│   └── java/com/botanical/launcher/
│       ├── pencil/              # 鉛筆の線と幾何
│       │   ├── Stroke.kt        #   筆圧・ぶれ・紙の目。コマごとに引き直す
│       │   └── Geometry.kt      #   蔓、葉、花弁
│       ├── flora/               # 版面の読み込み
│       ├── data/                # アプリ一覧と割り当ての永続化
│       └── ui/
│           ├── FloraCanvas.kt   # 版面の描画
│           ├── Wind.kt          # 風
│           ├── Reach.kt         # アプリを開くときに伸びる蔦
│           ├── HomeScreen.kt    # 状態とタップ処理
│           └── AppDrawer.kt     # アプリ一覧
└── tools/flora/                 # 素材づくり（Python）
    ├── pencil.py                #   鉛筆の線
    ├── leaves.py                #   葉の型（披針・広卵・羽状複葉・掌状）
    ├── shapes.py                #   釣鐘・星形・蕾
    ├── plate.py                 #   版面の構図
    ├── build_assets.py          #   器官を 1 つずつ焼いて manifest を書く
    └── preview.py               #   端末に入れる前に動きを確かめる
```

## 導入

Releases から `Herbarium-*.apk` を落として開き、**設定 → アプリ → デフォルトのアプリ
→ ホームアプリ** で `Herbarium` を選ぶ。

## 操作

| 操作 | 動き |
|---|---|
| 花・葉をタップ | 蔦が伸びて花が開き、アプリが起動する。複数なら枝分かれして並ぶので選ぶ |
| 花・葉を長押し | その部位にアプリを割り当てる（複数選択可） |
| 蕾をタップ | 花弁がほどけて開き、アプリ一覧が咲き広がる |
| 紙の余白を長押し | アプリ名の表示、タップ範囲の可視化、割り当ての解除 |
| 戻る | 蔦を引っ込める／一覧を閉じる |

## なぜこの作りなのか

### 絵は描き起こしている

最初はスキャン画像を使っていたが、**1 枚の絵は歪ませることしかできない**。蕾が
ほどける、葉が茎から捻れる、といった動きは原理的に作れなかった。植物を部品から
組み立てて描くことにした。

### 色を使わない

色を抜いた図版は銅版画・石版画の線描そのもので、**面と陰影はハッチングの密度で
作る**。色で誤魔化さないぶん、線の設計がそのまま絵の質になる。

### 線の階層（版面幅 1100px での目安）

| | 太さ | 役割 |
|---|---|---|
| 茎 | 12 → 3.4px | 2 回重ねて芯を作る。3 回以上重ねると線が割れて汚れになる |
| 葉の輪郭 | 1.5px | 細く。太いと塗り絵の線になる |
| 主脈 | 1.3px | |
| 側脈 | 0.8px | |
| ハッチング | 0.8px を 1 枚に 90 本 | ここが調子を作る |

**濃さは線の間隔で作る。** 線を濃くしても間隔が空いていれば全体は白いままで、
白地に濃い線が 1 本あるだけになる。本数を惜しむと平板になる。

**彫りの向きは側脈に沿わせる。** 葉の長手方向に走らせると木目や段ボールに見える。

### 密度と動きの両立

ハッチングは葉 1 枚に 90 本引くので、毎フレーム描き直すには重すぎる。そこで

- **葉と花は 1 つずつ画像に焼き**、毎フレームは付け根を軸に回すだけにした
- **茎と伸びる蔦だけは線を直に引く**（形が毎フレーム変わるため）
- **蕾は 12 コマ焼いてある**。花弁は常に同じ枚数を描き、開き具合で角度と大きさを
  変える。閉じているときは深く重なるので外側の 1 枚の輪郭だけが見え、蕾になる

### 描き直しは 11 コマ / 秒

線のゆらぎ（boiling line）は手描きアニメと同じで、滑らかにしすぎるとかえって
CG に見える。風の位相は滑らかに動かし、線の引き直しだけ 11 コマ / 秒に落として
いる。軽くもなる。

### 揺れの速さの倍率は整数

整数でないと位相が 1 周するたびに動きが飛ぶ。基準周期を 22 秒と長く取り、
遅いうねりと速い震えを同じ位相から作っている。

## 素材を作り直す

```bash
pip install pillow numpy scipy
cd android-launcher/tools/flora

# 構図を確かめる（1 枚絵）
python3 plate.py

# 器官を 1 つずつ焼いて manifest を書く
python3 build_assets.py

# 端末に入れる前に動きを確かめる
python3 preview.py --still --out still.png
python3 preview.py --seconds 6 --out motion.gif
python3 preview.py --seconds 5 --bloom --out bloom.gif
```

`build_assets.py` の出力先を `app/src/main/assets/flora/` に置き換えれば反映される。
構図は `plate.py` の `STEMS`（根元の位置、角度、丈、葉の型、花序）で決まる。

## ビルドと配布

```bash
./gradlew assembleDebug
```

`android-launcher/` に変更を入れると CI が APK をビルドし、Actions の成果物として
90 日置く。Release を作るときは Actions から **Herbarium Launcher Build** を手動
実行し、`release_tag` にタグ名を渡す。

### 署名

`keystore/debug.keystore` をリポジトリに置き、debug ビルドはこれで署名する。
既定のデバッグ鍵はビルドする機械ごとに自動生成されるため、手元で作った APK と
CI が作った APK で署名が変わり、上書き更新が「アプリがインストールされていません」
で弾かれる。パスワードは Android のデバッグ鍵の慣例値で、秘匿する意味はない。
