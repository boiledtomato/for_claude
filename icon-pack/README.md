# 画家スタイル・アイコンパック（叩き台）

有名画家の風合いで Android のアプリアイコンを描き分けるアイコンパックの試作。
現段階は**風合い確認用のサンプル画像のみ**で、アプリ化はまだしていない。

- `samples/overview.png` — 6 画家 × 12 アイコンの一覧
- `samples/<painter>.png` — 画家ごとのシート（未対応アプリのフォールバック例つき）
- `tools/render_samples.py` — サンプルを描く手続き的レンダラー（Pillow + NumPy のみ、生成 AI 不使用）

```bash
python icon-pack/tools/render_samples.py   # 約 1.5 分
```

各画家は**参考作品を 1 点に決め**、その構図・モチーフ・配色を下地と図柄の塗りに落とし込んでいる。

| `seurat` | スーラ | 『グランド・ジャット島の日曜日の午後』1884–86 | セーヌ川と帆、日なたの芝、手前の木陰、右の幹 — すべて点描 | 散策する人々の暗い菫色のシルエット、縁に橙、周りに明るい暈 |

## v3: 聖なる持物（アトリビュート）パック — `samples/attributes/`

画家の画風路線（v1・v2）をやめ、**Android 標準アプリ 12 種それぞれに、機能と結びつく理由のある
キリスト教美術の聖人・持物**を割り当てて描く路線。全アイコン共通の下地は金地の祭壇画パネル
（箔の継ぎ目・縁の刻線と点刻・彩色の円光）。`tools/render_attributes.py` が 1024px で描いて縮小する。

| アプリ | 持物 | 聖人・典拠 | 結びつけの理由 |
|---|---|---|---|
| 電話 | 白百合 | 大天使ガブリエル | 受胎告知の「告げる者」。1951 年ピウス 12 世が電信・電話・放送の守護聖人に |
| メッセージ | 聖霊の鳩（＋オリーブの枝） | ペンテコステ（使徒言行録 2 章） | 言葉が各国の人にそれぞれの言語で通じた日。オリーブはノアへの鳩の便り |
| カメラ | 聖顔布 | 聖ヴェロニカ | 布に像がそのまま写った「真の像（vera icon）」。写真家の守護聖人 |
| ギャラリー | 聖母の板絵と絵筆 | 聖ルカ | 最初に聖母子を描いたと伝わる。画家の守護聖人（聖ルカ組合） |
| メール | 書簡（封蝋 Π）と剣 | 使徒パウロ | 各地の教会へ宛てた書簡が新約聖書に。剣は殉教の印 |
| ブラウザ | 十字架つき水晶宝珠 | サルヴァトール・ムンディ | 手に載せた「世界」。レオナルドの作では水晶 |
| マップ | 帆立貝 | 聖ヤコブ（サンティアゴ巡礼） | 巡礼路の道標は今も青地に黄の帆立貝 |
| ミュージック | 携帯オルガン | 聖チェチーリア | 音楽の守護聖人 |
| 設定 | 棘の車輪（折れた車輪） | アレクサンドリアの聖カタリナ | 歯車に似た車輪。車大工・機械工の守護聖人 |
| カレンダー | 復活の大ろうそく（Α・Ω・2026・五つの香粒） | 復活徹夜祭 | 司祭がその年の数字を刻み「時も世々も主のもの」と唱える |
| 時計 | 砂時計 | 聖ヒエロニムス（デューラー 1514） | 書斎の壁の砂時計＝時の過ぎゆく印 |
| 天気 | 虹と箱舟 | ノアの契約（創世記 9:13） | 雨の後に雲の中に置かれた約束のしるし |

題材はすべてパブリックドメインの伝統図像で、特定の近代作品の構図には依存しない。

## v4: 北方ルネサンス版 — `samples/northern/`

v3 と同じ持物・同じ理由づけのまま、描き方を初期ネーデルラント絵画に寄せた版。
`tools/render_northern.py` が v3 の持物を黒地・白地で 2 回描き、その差から不透明度を取り出して（差分マット）
新しい舞台に置き直す。

- 金地をやめ、左上の窓から光が入る暗い壁（釉をかけた単色、ザクロ文様の錦、板張り）
- 肖像画の手前に描かれる石の棚に持物を置き、右下へ影を落とす
- 光沢面に窓の映り込み、樫の額縁と金の細縁、油の黄変と細かな亀裂
- 電話はメムリンク『花瓶の花』の IHS 入りマヨリカ水差しと絨毯、メールはホルバイン『ゲオルク・ギーゼ』の
  壁の桟に挟んだ手紙、天気はパティニールの「世界風景」を窓の外に描く

## v5: フェルメール版 — `samples/vermeer/`

持物と理由づけは v3 のまま、全点をフェルメールの画風に揃えた版（`tools/render_vermeer.py`）。

- 左端の鉛枠の窓（色ガラスの紋章入り）から差す昼光が、白い漆喰壁を斜めに流れる。壁には釘と釘穴
- 手前のテーブルに、襞で文様がうねるトルコ絨毯、または群青の布
- ハイライトに光の粒（ポワンティエ）、全体に柔らかなにじみ、光は鉛錫黄の温かさ・影は青灰
- 額は 17 世紀オランダの黒檀の波形縁
- 電話の水差しは『牛乳を注ぐ女』の卓上にあるライン地方の灰釉炻器、マップは壁の地図（『絵画芸術』）、
  ギャラリーとミュージックは壁に黒枠の絵、天気は『デルフトの眺望』に虹と箱舟

## v6: 縦長の額装・『真珠の耳飾りの少女』の筆致 — `samples/vermeer_portrait/`

`tools/render_vermeer_portrait.py`。持物と理由づけは v3 のまま。

- アイコンの外形は縦長（約 3:4）の絵画。黒檀の波形額に入れ、壁の釘から紐で吊り、壁に影を落とす。
  額の外は透明で、ホーム画面の壁紙が透ける
- 地は『真珠の耳飾りの少女』のような暗い黒、左上の一灯で持物が闇から浮かぶ。卓には群青の布
- 画面全体を 3 層の筆致（大・中・小）で塗り直し、絵具の盛り上がりに左上から光を当てる。
  明部と布ほど筆跡が見え、半分ほどを溶かした下層に戻してなめらかさを保つ。ハイライトに光の粒
- 天気だけは『デルフトの眺望』の屋外風景
