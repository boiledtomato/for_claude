# 画家スタイル・アイコンパック（叩き台）

有名画家の風合いで Android のアプリアイコンを描き分けるアイコンパックの試作。
現段階は**風合い確認用のサンプル画像のみ**で、アプリ化はまだしていない。

- `samples/overview.png` — 6 画家 × 12 アイコンの一覧
- `samples/<painter>.png` — 画家ごとのシート（未対応アプリのフォールバック例つき）
- `tools/render_samples.py` — サンプルを描く手続き的レンダラー（Pillow + NumPy のみ、生成 AI 不使用）

```bash
python icon-pack/tools/render_samples.py   # 約 1.5 分
```

各画家は**参考作品を 1 点に決め**、その構図・モチーフ・配色を下地と図柄の塗りに落とし込んでいる。

| `seurat` | スーラ | 『グランド・ジャット島の日曜日の午後』1884–86 | セーヌ川と帆、日なたの芝、手前の木陰、右の幹 — すべて点描 | 散策する人々の暗い菫色のシルエット、縁に橙、周りに明るい暈 |

作品の構図を明確に引用するこの 2 点は、商用版では作風のみに寄せるか権利者の許諾が要る。

図柄はブランドロゴではなく汎用アイコン（電話・カメラ等）。
