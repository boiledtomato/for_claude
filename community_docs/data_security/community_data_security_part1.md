About the Data Classification category

The Data Classification Category is aimed at discussions regarding the tools available to determine if the data Zscaler sees matches something sensitive that is relevant.

Example- Phrase matching can be a very specific unique identifier for a sensitive document

Example- Exact data match is looking for a specific key field (like SSN) + specific context (first and last name)
