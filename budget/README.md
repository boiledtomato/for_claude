# 家計簿アプリ

レシートの内容（日付・カテゴリ・金額）を手で入力して、月ごとの支出を集計し、
グラフで見るためのブラウザアプリです。無料で、インストールも会員登録も要りません。

公開先: `https://boiledtomato.github.io/for_claude/budget/`
（`main` にマージされ、`daily-update.yml` が走った後に反映されます）

## できること

| | |
|---|---|
| 入力 | 日付・カテゴリ・金額・メモ。金額は `1,280` のようにカンマ入りでも全角でも通ります |
| カテゴリ | 「＋」ボタンで自由に追加。追加したものはプルダウンに並びます |
| 月次比較 | 2 つの月を選んで円グラフ 2 枚で並べ、下の表にカテゴリごとの差額と増減率 |
| 通期推移 | 月別合計の折れ線と、カテゴリ別積み上げ棒グラフ。期間は 6/12/24 か月・全期間 |
| 共有 | Google スプレッドシートを保管場所にして、2 台以上の端末で同じデータを見る |
| 持ち出し | JSON（バックアップ・端末間の受け渡し用）と CSV（Excel 用）の書き出し |

外部ライブラリは一切使っていません。グラフは手書きの SVG、データは
`localStorage`、HTML・CSS・JS はすべて `index.html` 1 枚に入っています。

## 2 人で共有する設定（初回だけ・10 分ほど）

同期を設定しなくても、その端末の中だけで普通に使えます。以下は 2 人で
同じデータを見たい場合の手順です。

1. Google ドライブで新しいスプレッドシートを作る
2. メニューの **拡張機能 → Apps Script** を開き、`apps-script/Code.gs` の中身を
   まるごと貼り付ける（元からあるコードは消す）
3. 先頭の `SHARED_TOKEN` を 2 人だけの合言葉に書き換えて保存
4. **デプロイ → 新しいデプロイ → 種類「ウェブアプリ」**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 表示された `https://script.google.com/macros/s/..../exec` という URL を控える
   （`/dev` で終わる URL ではなく `/exec` の方）
6. アプリの **設定** タブで URL と合言葉を入れて「保存して接続テスト」
7. もう一方の端末でも、同じ URL と合言葉を入れる

`支出` と `カテゴリ` の 2 枚のシートが自動で作られます。スプレッドシートを
直接開いて中身を読むこともできます（支出シートにはカテゴリ名の列も入ります）。

### セキュリティについて

- 「アクセスできるユーザー: 全員」で公開するので、**URL と合言葉の両方を知って
  いる人は読み書きできます**。この 2 つは公開リポジトリや SNS に貼らず、
  2 人の間だけで受け渡してください。
- URL と合言葉はブラウザの `localStorage` にだけ保存されます。リポジトリにも
  GitHub Pages にも入りません。
- 家計のデータ自体も、同期を設定するまでは端末の外に出ません。

## 同期のしくみ

行ごとの last-write-wins です。

- 各行（支出 1 件・カテゴリ 1 件）が `updatedAt` を持つ
- 端末は未送信の行だけを送る → サーバーが `updatedAt` の新しい方を採用 → 全件を返す
- 端末はその結果で丸ごと置き換える（送信中に入力した分だけは手元の内容を残す）
- 削除は行を消さず `deleted` を立てる。そうしないと相手の端末で復活してしまう

同期のタイミングは、入力の 1.2 秒後・タブに戻ったとき・60 秒ごと・ヘッダの
バッジをクリックしたとき、です。オフライン中の入力は手元に残り、回線が戻った
ときにまとめて送られます。

初期カテゴリ 8 件は端末によらず同じ id (`c_default_0`〜`7`) で、更新時刻が
エポック（1970 年）になっています。こうしておくと、2 台目が後から参加しても
初期値が二重にならず、相手がすでに名前や色を変えていればそちらが必ず勝ちます。

## グラフの色について

系列色は 8 スロットの固定パレットで、色覚多様性を考慮した検証済みの並びです
（ライト・ダークとも）。カテゴリと色は 1 対 1 で結びつき、順位では塗り替わりません。

- 円グラフは 6 区分まで、積み上げ棒は 8 系列まで。あふれた分は灰色の「その他」に
  まとまります（金額はすべて表側に出ています）
- 9 個目以降のカテゴリは既存の色と重複しうるので、**同じ色が 2 つ並ぶ場合は
  金額の小さい方を「その他」に送ります**。グラフ上で同じ色の区分が 2 つ出ることは
  ありません

## ローカルで動かす

```bash
python -m http.server 8000
# → http://localhost:8000/budget/
```

`file://` で直接開いても動きますが、ブラウザによっては制限があるので
簡易サーバー越しを勧めます。
