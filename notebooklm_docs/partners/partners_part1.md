The Zscaler and 1Password Deployment Guide provides instructions on using Zscaler Internet Access (ZIA) and Zscaler Private Access (ZPA) features with 1Password-Kolide.

1Password-Kolide is a solution that focuses on enhancing endpoint security through continuous monitoring, automated compliance checks, and user engagement. You can prevent devices that have the Kolide and Zscaler integration installed from accessing any apps behind SSO unless Zscaler is installed, running, and properly configured.

Integrating Zscaler and 1Password strengthens an organization's security posture by combining robust credential management with advanced threat protection and secure access controls.

[Zscaler and 1Password Deployment Guide](https://help.zscaler.com/downloads/zscaler-technology-partners/b/zscaler-and-1password-deployment-guide/Zscaler-1Password-Deployment-Guide-FINAL.pdf) [Download PDF](https://help.zscaler.com/downloads/zscaler-technology-partners/b/zscaler-and-1password-deployment-guide/Zscaler-1Password-Deployment-Guide-FINAL.pdf)

## Video Links

View a Zscaler and 1Password integration demonstration in [Setting up the 1Password Device Trust and Zscaler Integration](https://vimeo.com/1117103682/7041f10e80).

To learn more, see [1Password Device Trust Integrates with Zscaler to Help Mutual Customers Secure Access and Reduce Risk](https://blog.1password.com/1password-announces-new-integration-with-zscaler).

Some 1Password and Zscaler users can experience connectivity issues. The issue is caused by users trying to connect to the 1Password application prior to Zscaler authenticating the user. Connections from unauthenticated users are redirected to log in to the Zscaler service, which triggers 1Password’s active defense system. 

To resolve the issue, add 1Password’s domains to the authentication exemptions list. To learn more, refer to the [1Password documentation](https://support.1password.com/ports-domains/).

To learn how to set up these exclusions in Zscaler, see [Exempting URLs and Cloud Apps from Authentication](https://help.zscaler.com/zia/exempting-urls-cloud-apps-authentication).

If you continue to experience issues after applying these changes, contact [1Password customer support](https://support.1password.com/) for assistance.

The Zscaler and Microsoft Defender for Cloud Apps Deployment Guide provides instructions on integrating Zscaler Internet Access (ZIA) with the Microsoft Defender cloud app security platform.

Microsoft Defender for Cloud Apps is a Cloud Access Security Broker (CASB) that supports various deployment modes including log collection, API connectors, and reverse proxy. It provides rich visibility, control over data travel, and sophisticated analytics to identify and combat cyberthreats across Microsoft and third-party cloud services.

ZIA log messages are stored in Zscaler Nanolog Streaming Service (NSS). When an organization deploys NSS for various log feeds, each NSS opens a secure tunnel to the Nanolog in the Zscaler cloud. The Nanolog then streams copies of the logs to each NSS in a highly compressed format to reduce bandwidth footprint. The original logs are retained on the Nanolog.

When NSS receives the logs from the Nanolog, it unscrambles them, applies the configured filters to exclude unwanted logs, converts the filtered logs to the configured output format so they can be parsed by Microsoft Defender for Cloud Apps, and then streams the logs to Microsoft Defender for Cloud Apps using an Authentication Token generated in the Microsoft Defender for Cloud Apps portal.

## Zscaler and Tanium Deployment Guide

- Source: https://help.zscaler.com/zscaler-technology-partners/zscaler-uvm-and-tanium-deployment-guide
- Product: Zscaler Technology Partners
- Path: Zscaler Technology Partners > T – Z > Zscaler and Tanium Deployment Guide

- Summary: The Zscaler and Tanium Deployment Guide provides instructions on how to configure Zscaler Client Connector and Unified Vulnerability Management (UVM) to work with Tanium Deploy and Autonomous Endpoint Management (AEM).

The Zscaler and Tanium Deployment Guide provides instructions on using Zscaler Client Connector and Unified Vulnerability Management (UVM) features with Tanium Deploy and Autonomous Endpoint Management (AEM).

This guide describes how to deploy Zscaler Client Connector to Windows devices in your environment using Tanium's Deploy module and integrate the UVM solution with AEM.

Deploy is a software management module that rapidly installs, updates, and removes software across large organizations with minimal infrastructure requirements.

Tanium's AEM suite is an endpoint management provider, offering advanced real-time visibility and control across extensive enterprise environments.

UVM ingests, normalizes, and unifies data across enterprise security and business systems to deliver actionable insights, analytics, and operational efficiencies.

UVM offers the following preconfigured Tanium AEM connectors:

- Tanium Assets: Retrieves essential asset data, such as serial number, computer ID, operating system, and IP address.
- Tanium Compliance: Retrieves a detailed list of all compliance findings on the endpoint, including ID, state, category, rule, first found date, and last scan date.
- Tanium CVE: Retrieves vulnerability data, including CVE ID, score, summary, last scan date, and severity.
